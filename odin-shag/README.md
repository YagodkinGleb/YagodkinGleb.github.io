# Один шаг

Небольшое веб-приложение с короткими инструкциями на день и перед сном.

Открыть: https://yagodkingleb.github.io/odin-shag/

## На iPhone

Откройте ссылку в Safari и добавьте на экран «Домой». Затем откройте с иконки с включённым интернетом и дождитесь надписи «Готово к работе без интернета». После первой загрузки инструкции, записи, галочки и таймеры работают без сети. Уведомлений и серверной синхронизации нет.

Записи хранятся локально в браузере. При переходе с другого домена они автоматически не переносятся. Очистка данных сайта удаляет записи и офлайн-копию.

## Файлы

- `index.html` — интерфейс, стили, инструкции и локальное сохранение.
- `sw.js` — сохранение приложения для офлайн-запуска.
- `manifest.webmanifest` и PNG-иконки — установка на главный экран.

Сборка и внешние библиотеки не нужны. При выпуске изменений одновременно меняйте `app-version` в HTML и `VERSION` в service worker, чтобы браузеры загрузили новую копию. Относительные пути рассчитаны на публикацию в подпапке GitHub Pages.
